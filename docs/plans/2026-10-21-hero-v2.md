# Plan: hero v2 (real 3D swarm, "Muhammad Ahsan")

Why: the owner called v1 "a static picture with a cursor effect". v1 is a flat
2D swarm in a box, starts with 1-4 s of a noise rectangle, and writes "Ahsan" in
the body font. Teardown of the reference (musa.ai) and the full reasoning:
`../../../docs/research/2026-10-21-musa-teardown-and-portfolio-verdict.md` (HQ).

## What changes

1. **New engine `src/lib/field.ts`** (plain three.js, own code):
   - GPGPU simulation (`GPUComputationRenderer`): position + velocity textures.
     Each particle is a spring toward its target with damping, so it overshoots
     and settles; pointer repels in 3D; click sends a shockwave; heat comes from
     speed and colours mint → orange → white. No per-particle work on the main thread.
   - Real camera: fly-in on load, gentle idle sway, drag to orbit (springs back),
     pointer parallax. Depth: text has thickness, far points fade, sparse star layer.
   - Word fitted to the hero's focus cell via `setViewOffset`, so it never crops on phones.
   - Particle budget: 128² desktop, 96² on ≤4-core desktops, 72² on phones. DPR ≤ 1.5.
   - Starts as a faint distant cloud that assembles during the fly-in (no noise box).
   - Reduced motion: targets drawn once, no sim, no camera motion.
   - No float/half-float render targets → falls back to the v1 `SwarmCanvas`.
2. **Wordmark "Muhammad Ahsan"** (two lines in the swarm) in Mona Sans 900 at
   width 125 (OFL, next/font, `wdth` axis); also in the header and footer.
3. **Type to rewrite**: a real input in the hero (works on phones); on desktop,
   typing anywhere while the hero is visible goes into it. Enter/Escape resets.
4. Pure math in `src/lib/field-math.ts` with unit tests (framing, pairing).
